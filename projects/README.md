# Скриншоты проектов

Одна папка на проект. Имя папки = `slug` проекта в `content/site.json`.

```
public/projects/
  nuxtgram/
    1.webp
    2.webp
    3.webp
  daregames/
    1.webp
    2.webp
    3.webp
    4.webp
  my-project/
    ...
```

Рекомендации:

- Формат: **WebP** (или PNG/JPG), ширина 1440–1920 px для десктопа и 390–430 px для мобильного.
- Десктопные скриншоты лучше снимать «по первому экрану» (viewport), а не всю длинную страницу.
- Изображения из папки подхватываются автоматически: `1.webp`, `2.webp`, `3.webp` и т.д.
- Манифест `app/data/project-images.json` пересобирается командой `bun run images:manifest` (а также автоматически при `dev`, `build` и `typecheck`).
- Поле `projects[].images` в `content/site.json` — только fallback для внешних URL или ручного списка; папка имеет приоритет.
- Если скриншотов больше одного, карточка сама добавит точки-индикаторы и стрелки, а при наведении/фокусе начнёт плавно перелистывать кадры.
- Портретные (мобильные) скриншоты показываются целиком, без обрезки.
- Если скриншотов нет, сайт автоматически покажет стилизованный fallback-браузер с инициалами проекта — карточка не выглядит сломанной.
