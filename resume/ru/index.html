Nuxtgram - Личный проектnuxtgram.mervik.ruGitHub

Instagram-подобная соцсеть: посты с фото, реакции, комментарии, подписки и профили. Главная идея — полностью serverless-архитектура без собственного бэкенд-монолита: только сервисы-провайдеры с чётким разделением ответственности. Вход через Clerk, а выданный им JWT служит ещё и токеном для прямого подключения клиента к SurrealDB — права на данные задаются permissions в схеме базы, а не фронтендом. Cloudflare Worker проверяет тот же JWT и отвечает за все медиа-операции поверх Cloudflare R2: presigned URL с TTL, проверка владельца, лимиты размера. Real-time работает на LIVE-подписках SurrealDB. Frontend — SPA на Nuxt 4 (Vue 3.5, TypeScript), статика на GitHub Pages; состояние в Pinia, формы на vee-validate + Zod, UI на @nuxt/ui и Tailwind CSS 4, юнит-тесты на bun:test. Проект вырос из self-hosted бэкенда на Payload CMS, который сохранён в legacy-репозитории (nuxtgram-backend), а текущая версия целиком переехала на serverless.
